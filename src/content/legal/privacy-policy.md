# Aido 개인정보처리방침

**시행일: 2026년 11월 10일** · 이전 방침: 2026년 3월 13일 시행(2026년 10월 4일·26일·27일 추가 안내 포함)

---

RedBand(이하 "회사")는 개인정보보호법, 정보통신망 이용촉진 및 정보보호 등에 관한 법률 등 관련 법령을 준수하며, 이용자의 개인정보를 안전하게 처리하기 위해 다음과 같이 개인정보처리방침을 수립·공개합니다.

### 이번 개정에서 달라진 점 (2026년 11월 10일, 앱 1.15.0)

- **말로 할 일 만들기·말로 메모하기**: 음성이 어디서 글자로 바뀌는지, 녹음 파일을 기기에만 저장하고 30일 뒤 지우는 방식, 회사 서버가 받아 적은 글자를 저장하지 않는다는 점을 적었어요(제2조, 제4조, 제8조의2).
- **AI 처리 업체**: Google에 더해 Anthropic·OpenAI가 AI 기능을 처리할 수 있어요. 새 안내에 동의한 회원에게만 적용되고, 업체별 보관 기간과 학습 사용 여부를 적었어요(제6조, 제7조, 제8조).
- **구독**: 연간 구독 2주 무료 체험과 체험 종료 3일 전·연간 갱신 7일 전 안내를 위해 처리하는 정보를 적었어요(제2조, 제3조).
- **알림**: 서비스·거래 알림과 광고성 알림을 나누고, 광고성 알림은 따로 동의한 회원에게만 보낸다는 점을 적었어요(제10조의2).
- **목록 정리**: 서버를 운영하는 Amazon Web Services와 운영자 알림에 쓰는 Discord를 위탁·국외 이전 목록에 더하고, 더 이상 쓰지 않는 Firebase Crashlytics와 카메라 접근을 뺐어요. AI 업체의 보관 기간을 각 업체의 현재 정책에 맞게 고쳤어요.

---

## 제1조 (개인정보처리방침의 목적)

본 개인정보처리방침은 회사가 제공하는 AI 기반 소셜 할 일 관리 서비스 "Aido"(이하 "서비스")를 이용하는 과정에서 수집·이용되는 개인정보의 처리에 관한 사항을 안내하기 위함입니다.

## 제2조 (수집하는 개인정보 항목 및 수집 방법)

### 2-1. 이용자 직접 제공

| 구분 | 수집 항목 | 필수/선택 |
|------|----------|----------|
| 이메일 회원가입 | 이메일 주소, 비밀번호, 사용자 태그(UserTag) | 필수 |
| 프로필 설정 | 이름(닉네임), 프로필 이미지 | 선택 |
| 고객 문의 | 문의 내용, 답변을 위한 연락처 | 필수 |
| 마케팅 정보 수신 동의 | 마케팅 정보(이메일) 수신 동의 여부, 광고성 앱 푸시 수신 동의 여부, 각각의 동의·철회 시점, 동의 사실을 2년마다 다시 알린 시점 | 선택 |
| AI 기능 데이터 제공 동의 | 동의·철회 여부, 답한 안내 버전, 동의 시점 | 선택 |
| AI 기능 이용 | AI로 정리할 글(직접 입력한 문장·메모, 음성 인식으로 바뀐 글자) — 정리에만 쓰고 회사 서버에 저장하지 않음(제8조) | AI 기능을 쓸 때 |
| 신고 | 신고 대상(신고된 회원과 콘텐츠의 종류·ID), 신고 사유, 상세 내용(500자 이내) | 신고 시 필수 (상세 내용은 선택) |

- **선택 항목의 동의 거부권**: 이용자는 선택 항목의 수집·이용에 동의하지 않을 수 있으며, 동의를 거부하더라도 서비스의 기본 기능 이용에는 제한이 없습니다. 다만, 선택 항목 미제공 시 프로필 표시, 마케팅 정보 수신, AI 기능 등 일부 부가 기능 이용이 제한될 수 있습니다.

### 2-2. 서비스 이용 과정에서 자동 수집

| 수집 항목 | 수집 목적 |
|----------|----------|
| 기기 정보 (기기 ID, 플랫폼(iOS/Android), 기기 모델, 앱 버전, User-Agent) | 서비스 최적화, 보안, 앱 버전별 기능 제공 |
| IP 주소 | 부정 이용 방지, 접근 기록 관리 |
| 앱 사용 기록 (접속 시간, 화면 조회, 이벤트 로그) | 서비스 개선, 오류 대응 |
| 푸시 토큰 (Expo Push Token) | 알림 발송 |
| 오류 정보 (Sentry: 오류 로그, 요청 정보, 오류가 난 화면의 재현 기록. 글자·이미지는 가려서 수집) | 앱·서버 안정성 개선 |
| 타임존 정보 (IANA 형식) | 알림 및 리마인더 시간대 설정 |
| 위치 정보 (위도·경도, 위치 권한을 허용한 경우에만) | 현재 위치 기반 날씨·대기질·일출·일몰 정보와 날씨 알림 제공 |
| 최종 로그인 시점 | 부정 이용 감지, 계정 관리 |
| 최종 활동 시점 | 비활성 사용자 감지, 서비스 개선 |
| 디바이스 지문 (User-Agent + IP 해시) | 세션 보안, 비인가 접근 감지 |
| AI 기능 사용 기록 (기능별 월간 사용 횟수, 요청마다의 차감·환불 기록, 같은 요청을 두 번 차감하지 않기 위한 요청 내용의 해시값(SHA-256)) | 요금제별 사용량 한도 관리, 차감 내역 안내 |
| 구독 정보 (스토어·RevenueCat에서 받는 상품, 구독 기간, 자동 갱신 여부, 무료 체험 여부, 스토어와 결제 환경, 국가, 결제 금액, 거래 ID) | 구독 상태 확인, 무료 체험 종료·연간 갱신 안내, 고객 문의 대응 |
| 차단 기록 (차단한 회원, 차단된 회원, 차단 시점) | 차단한 회원과의 친구 연결·상호작용 제한, 서로의 콘텐츠 숨김 |
| 신고 처리 상태, 신고 시점 | 신고 검토 및 처리 관리, 반복·중복 신고 제한 |
| 초대 수락 시 앱 설치 식별자(iOS는 기기 키체인에 저장한 최초 IDFV 값, Android는 Android ID)와 인증한 이메일 또는 소셜 로그인 계정 ID의 해시값 (HMAC-SHA256, 원래 값은 저장하지 않음) | 친구 초대 보상의 중복 수령 방지(부정 사용 방지) |
| 앱 설치 식별자 (iOS: 기기 키체인 `aido_installation_id`에 저장, 서버에는 해시값만 저장) | 친구 초대 보상의 중복 수령 방지. 앱을 삭제해도 기기를 초기화하기 전까지 남을 수 있음 |

- 서비스는 광고 식별자(IDFA·Android 광고 ID)를 수집하지 않으며, 다른 회사의 앱·웹사이트에서 모은 정보와 연결해 이용자를 추적하지 않습니다.

### 2-3. 기기 권한과 기기에 저장하는 정보

다음 권한은 이용자가 해당 기능을 처음 쓸 때 기기의 안내 창으로 허락을 받으며, 기기의 설정에서 언제든지 바꾸거나 철회할 수 있습니다. 권한을 허용하지 않아도 그 기능을 뺀 나머지 기능은 그대로 쓸 수 있습니다.

| 권한 | 쓰는 곳 |
|------|--------|
| 마이크 | 말로 할 일 만들기, 말로 메모하기, 하위 할 일 받아쓰기. 버튼을 누른 뒤에만 쓰며 앱이 백그라운드에 있을 때는 녹음하지 않음 |
| 음성 인식 | 말한 내용을 글자로 바꾸기. 처리하는 곳은 제8조의2 |
| 위치 (앱을 사용하는 동안만) | 날씨 화면과 날씨 알림. 백그라운드 위치는 쓰지 않음 |
| 알림 | 할 일 리마인더, 친구 소식, 결제 안내 등 푸시 알림 |
| 사진 보관함 (추가) | 공유 이미지를 사진 보관함에 저장. 보관함의 사진을 읽어 회사 서버로 보내지 않음 |

- **기기에만 저장하는 정보**: 말로 메모하기의 녹음 파일과 받아 적은 글자·요약은 이용자의 기기에 저장하고 회사 서버로 보내지 않습니다. 만든 날부터 30일이 지나면 자동으로 삭제되며, 앱의 **마이** 탭 > **녹음 저장 공간**에서 먼저 지울 수 있습니다. 기기 백업(iCloud, Google 백업 등)을 켜 두었다면 백업에 포함될 수 있습니다. 정리 결과 가운데 이용자가 저장을 고른 할 일·메모만 회사 서버에 저장됩니다.

### 2-4. 소셜 로그인(OAuth) 시 제3자로부터 제공받는 정보

| OAuth 제공자 | 제공받는 항목 |
|-------------|-------------|
| **Google** | 이메일 주소, 이름, 프로필 이미지 |
| **카카오(Kakao)** | 이메일 주소, 닉네임, 프로필 이미지 |
| **네이버(Naver)** | 이메일 주소, 이름, 프로필 이미지 |
| **Apple** | 이메일 주소 (이름은 최초 로그인 시에만 제공, Apple 정책에 따라 이메일 가림 가능) |

- 소셜 로그인을 통해 제공받는 정보는 해당 OAuth 제공자의 정책에 따르며, 이용자가 제공자에서 설정한 공개 범위에 따라 달라질 수 있습니다.

## 제3조 (개인정보의 처리 목적)

회사는 수집한 개인정보를 다음의 목적을 위해서만 처리합니다.

| 처리 목적 | 상세 내용 |
|----------|----------|
| 회원 관리 | 회원 식별, 가입·탈퇴 처리, 본인 확인, 부정 이용 방지 |
| 서비스 제공 | 할 일 관리, 반복 할 일, 캘린더(주간/월간), 친구 공유, 콕 찌르기, 응원(Cheer), 소셜 다이제스트(친구들의 주간 활동 요약), 주간 성취 배지, 스트릭(연속 달성), 현재 위치 기반 날씨 등 핵심 기능 제공. 공개 설정된 할 일은 맞팔(상호 팔로우) 친구에게 표시되며, 콕 찌르기 및 응원 메시지는 상대방에게 전달됩니다. |
| AI 기능 제공 | 입력한 문장·메모를 할 일로 정리, 말로 할 일 만들기, 말로 메모하기(요약·핵심 포인트·할 일 정리), 주간·월간 AI 리포트 생성, 반복 할 일 제안 (AI 기능 데이터 제공 동의를 받은 경우, 제8조) |
| 구독 및 결제 관리 | 유료 구독과 무료 체험 상태 확인, 영수증 검증, 무료 체험 종료 3일 전·연간 구독 갱신 7일 전 안내, 결제 문의 대응 |
| 알림 발송 | 서비스 알림(할 일 리마인더, 아침·저녁 리마인더, 날씨 알림, 친구 요청·콕 찌르기·응원 등 소셜 알림, AI 리포트, 사용법 안내, 서비스 공지)과 거래 알림(무료 체험 종료·연간 갱신·보상 프리미엄 종료 안내, 광고성 정보 수신 동의 확인) |
| 서비스 개선 | 이용 통계 분석, 오류 대응, 서비스 품질 향상 |
| 부정 사용 방지 | 친구 초대 보상을 같은 기기나 같은 계정 정보로 반복해서 받는 것을 방지 |
| 이용자 보호 | 차단한 회원과의 친구 요청·초대 수락·콕 찌르기·응원·댓글·답글·좋아요 제한 및 서로의 콘텐츠 숨김, 신고 접수·검토와 운영 정책 위반에 대한 조치 |
| 고객 지원 | 문의 응대, 불만 처리, 공지 전달 |
| 마케팅(선택) | 이벤트·혜택 소식과 광고성 앱 푸시(복귀 안내, 스트릭 위기·점심 알림, 콕 찌르기 제안, 소셜 다이제스트, AI 반복 할 일 제안 알림, 친구 초대 조건 알림 등) 발송 — 따로 동의한 회원에게만(제10조의2) |

## 제4조 (개인정보의 보유 및 이용 기간)

회사는 원칙적으로 개인정보의 수집·이용 목적이 달성되면 지체 없이 파기합니다. 다만, 관계 법령에 따라 보관이 필요한 경우 아래 기간 동안 보관합니다.

| 보관 항목 | 보관 기간 | 근거 법령 |
|----------|----------|----------|
| 계약 또는 청약 철회 등에 관한 기록 | **5년** | 전자상거래법 제6조 |
| 대금 결제 및 재화 등의 공급에 관한 기록 | **5년** | 전자상거래법 제6조 |
| 소비자의 불만 또는 분쟁 처리에 관한 기록 | **3년** | 전자상거래법 제6조 |
| 표시·광고에 관한 기록 | **6개월** | 전자상거래법 제6조 |
| 서비스 접속 기록(로그인 기록, 접속 로그) | **3개월** | 통신비밀보호법 제15조의2 |
| 본인 확인에 관한 기록 | **6개월** | 정보통신망법 제44조의5 |

### 서비스 운영 데이터 보유 기간

| 데이터 항목 | 보유 기간 | 보유 근거 |
|------------|----------|----------|
| 보안 로그(SecurityLog) | **90일** | 부정 이용 방지 및 보안 감사 |
| 로그인 시도 기록(LoginAttempt) | **30일** | 비정상 로그인 탐지 및 차단 |
| 알림 데이터(Notification) | **90일** | 알림 이력 조회 및 서비스 제공 |
| 세션 정보(Session) | **세션 만료 또는 폐기 시** | 인증 및 접근 관리 |
| 일일 완료 기록(DailyCompletion) | **회원 탈퇴 시까지** | 스트릭·통계 등 핵심 서비스 제공 |
| 주간 달성 기록(WeeklyAchievement) | **회원 탈퇴 시까지** | 주간 성취 배지·통계 서비스 제공 |
| AI 리포트(AiReport) | **회원 탈퇴 시까지** | AI 리포트 열람 서비스 제공 |
| AI 정리에 보낸 글(받아 적은 글자 포함) | **회사 서버에 저장하지 않음** (같은 요청에 다시 답하기 위해 정리 결과만 서버 메모리에 최대 10분 보관) | AI 기능 제공 |
| AI 사용량 기록(QuotaUsage·QuotaCharge) | **회원 탈퇴 시까지** (요청 내용의 해시값은 **7일** 뒤 삭제) | 요금제별 한도 관리, 차감·환불 내역 안내 |
| 말로 메모하기 녹음·받아 적은 글자·요약 (이용자 기기에 저장) | **만든 날부터 30일** 뒤 자동 삭제 (그 전에 직접 지울 수 있음) | 다시 듣기와 정리 |
| 위치 정보(UserLocation, 마지막으로 받은 위도·경도) | **회원 탈퇴 시까지** (새 위치를 받으면 이전 위치는 지워짐) | 현재 위치 기반 날씨 정보 제공 |
| 구독 정보(Subscription, 무료 체험·갱신 안내 발송 기록 포함) | **회원 탈퇴 시까지** (결제 관련 기록은 위 법령 기간) | 구독 상태 확인과 결제 안내 |
| 초대 관계·수락·활동일·보상 기록 | **회원 탈퇴 시까지** | 친구 초대 및 보상 서비스 제공 |
| 보상 중복 수령 방지용 해시값(RewardClaim) | **부정 사용 방지 목적이 유지되는 동안 (회원 탈퇴 후에도 보관)** | 친구 초대 보상의 반복 수령 방지 |
| 차단 기록(UserBlock) | **차단 해제 또는 차단한 회원·차단된 회원의 탈퇴 시까지** | 차단 기능 제공 |
| 신고 기록(UserReport: 신고한 회원, 신고 대상, 사유, 상세 내용, 처리 상태) | **신고한 회원 또는 신고된 회원의 탈퇴 시까지** | 신고 검토, 반복 위반 대응 |
| AI 기능 데이터 제공 동의 기록(동의 여부, 안내 버전, 동의 시점) | **회원 탈퇴 시까지** (철회하면 동의 시점은 지우고 철회 상태를 남김) | 동의 여부 확인 및 처리 근거 관리 |
| 마케팅·광고성 앱 푸시 수신 동의 기록 | **회원 탈퇴 시까지** | 동의 여부 확인, 2년마다 동의 사실 안내 |

- 회원 탈퇴 시, 회사는 **30일간의 유예 기간**을 둔 후 개인정보를 파기합니다. 유예 기간 내에 재로그인하면 계정이 복구되며, 유예 기간 경과 후에는 위 법정 보관 기간이 남아 있는 정보를 제외한 개인정보가 영구 삭제됩니다.
- 초대 관계와 보상 기록은 회원 탈퇴 시 계정과 함께 삭제됩니다. 다만 보상 중복 수령 방지용 해시값은 사용자 정보와 연결되어 있지 않고 개인을 식별할 수 없으며, 부정 사용 방지를 위해 회원 탈퇴 후에도 보관합니다.
- 차단 기록, 신고 기록과 AI 기능 데이터 제공 동의 기록은 유예 기간이 지나 계정이 영구 삭제될 때 함께 삭제됩니다. 신고 기록은 신고한 회원과 신고된 회원 중 어느 한쪽의 계정이 영구 삭제되어도 삭제됩니다. 운영자에게 이메일로 보낸 신고 접수 알림은 신고 처리와 관련 분쟁 대응에 필요한 기간 동안 보관한 뒤 파기합니다.
- 이용자 기기에만 저장된 말로 메모하기 녹음은 회사가 지울 수 없으므로, 회원 탈퇴와 별개로 위 30일 자동 삭제, 앱의 녹음 저장 공간, 앱 삭제로 지워집니다. 같은 기기에서 다른 계정으로 로그인하면 이전 계정의 녹음은 지워집니다.

## 제8조 (AI 기능과 데이터 처리)

1. **AI 기능**: 서비스는 다음 AI 기능을 제공하기 위해 회원의 데이터를 외부 AI 업체로 보냅니다.
   - **할 일 정리**: 직접 입력한 문장이나 메모를 제목·날짜·시간·카테고리가 있는 할 일로 정리
   - **말로 할 일 만들기**: 말한 내용을 글자로 바꾼 뒤 할 일 계획으로 정리. 이용자가 고른 할 일만 저장
   - **말로 메모하기**: 긴 녹음을 글자로 바꾼 뒤 요약·핵심 포인트·할 일로 정리
   - **주간·월간 AI 리포트**와 **반복 할 일 제안** (프리미엄)
2. **보내는 내용**

   | 기능 | 보내는 내용 |
   |------|------------|
   | 할 일 정리, 말로 할 일 만들기, 말로 메모하기 | 입력하거나 말한 글(음성은 음성 인식으로 바뀐 글자), 카테고리 이름, 현재 날짜와 시간대. 말로 할 일 만들기·말로 메모하기는 이미 있는 할 일과 겹치는지 알아내기 위해 다가오는 할 일의 제목(앞 80자)·날짜·반복 여부(최대 30개)를 함께 보냄 |
   | AI 리포트 | 그 기간의 할 일 집계 통계(전체·완료 수, 달성률, 연속 달성일, 카테고리별·요일별·시간대별 분포, 이전 기간과의 차이), 카테고리 이름, 이전 리포트의 팁 |
   | 반복 할 일 제안 | 할 일 제목(앞 80자), 카테고리 이름, 요일별 기록과 기록된 시각, 이전 제안에 대한 응답 |

3. **보내지 않는 내용**: 이름, 이메일, 친구 정보, 녹음 파일은 보내지 않습니다.
4. **받는 곳**: Anthropic(Claude), Google(Gemini), OpenAI. 회사가 정한 순서에 따라 먼저 한 곳에 보내고, 그 업체가 응답하지 못하면 같은 내용을 다음 업체에 보냅니다. 업체별 보유 기간과 학습 사용 여부는 제7조에 있습니다.
5. **쓰는 곳**: AI 기능의 결과를 만드는 데만 쓰며, 광고·마케팅에는 쓰지 않습니다.
6. **회사 서버의 처리**: AI 정리에 보낸 글(받아 적은 글자 포함)은 정리에만 쓰고 회사 서버에 저장하지 않습니다. 같은 요청을 두 번 차감하지 않도록 요청 내용을 되돌릴 수 없게 바꾼 값(SHA-256)을 7일 동안, 같은 요청에 다시 답하기 위해 정리 결과를 서버 메모리에 최대 10분 동안 둡니다. 서버 로그, 오류 추적(Sentry), 앱 이용 분석에는 말한 내용·받아 적은 글자·할 일 제목을 남기지 않습니다. 이용자가 확인하고 저장한 할 일과 메모는 일반 할 일·메모와 똑같이 저장됩니다.
7. **AI 기능 데이터 제공 동의**
   - 앱 1.13.0부터 AI 기능을 처음 쓰기 전에 보내는 내용·받는 곳·쓰는 곳을 알리고 동의를 받습니다. **나중에**를 누르거나 안내를 닫으면 아무것도 보내지 않고 그 AI 기능만 실행하지 않으며, 다음에 AI 기능을 쓸 때 다시 물어봅니다. 서버도 동의하지 않은 회원의 AI 요청을 처리하지 않습니다.
   - 동의하거나 철회하면 그 선택과 안내 버전, 동의 시점을 저장합니다. 안내 내용이 바뀌면 새 안내에 다시 동의를 받으며, 철회한 선택은 안내가 바뀌어도 그대로 유지합니다.
   - **안내 버전별 받는 곳**: 2026년 11월 4일 안내(앱 1.15.0)에 동의한 회원은 Anthropic·Google·OpenAI, 2026년 10월 26일 안내(앱 1.13.0~1.14.x)에만 동의한 회원은 Google만 씁니다. 앱 1.15.0은 이전 안내에 동의한 회원에게 바뀐 안내를 한 번 보여 주며, 답하지 않으면 이전처럼 Google만 씁니다.
   - **철회**: 앱의 **마이** 탭 > **약관 및 정책** > **AI 기능 데이터 제공**에서 언제든지 철회하거나, 동의한 적이 없어도 동의하지 않기로 정할 수 있습니다. 철회한 뒤에는 AI 기능에 데이터를 보내지 않으며, 이미 만든 할 일은 그대로 남습니다.
   - **예약 생성 기능**: 프리미엄 회원의 주간·월간 AI 리포트와 반복 할 일 제안은 서버가 정해진 때에 미리 만들어 둡니다. 동의하지 않은 회원의 리포트는 AI 업체 없이 할 일 기록 통계만으로 만들고, 반복 할 일 제안은 만들지 않습니다. 직접 요청한 기능은 앱 요청 헤더의 앱 버전으로, 예약 기능은 계정과 기기에 기록된 가장 최신 앱 버전으로 동의 절차 적용 여부를 판단합니다.
   - **1.13.0 미만 앱**: 동의 화면이 없는 이전 버전 앱만 쓰는 회원은 동의하지 않기로 정하지 않았다면 이전과 같이 Google에만 보내 처리합니다. 원하지 않으면 앱을 업데이트해 동의하지 않기로 정하거나 제12조에 따라 이메일(matthew@redband.co.kr)로 처리 정지를 요청할 수 있습니다.
8. **AI 결과의 한계**: AI와 음성 인식은 말이나 날짜를 잘못 알아듣거나 사실과 다른 내용을 만들 수 있습니다. 말로 할 일 만들기와 메모 정리는 이용자가 결과를 확인하고 고른 것만 저장하며, 잘못된 결과는 앱의 **문의하기**로 알려 주실 수 있습니다.

## 제8조의2 (음성 기능과 녹음)

1. **음성이 글자로 바뀌는 곳**: 말한 내용은 이용자 기기의 운영체제가 제공하는 음성 인식으로 글자로 바뀝니다. 기기에서 바로 인식할 수 없으면 음성이 Apple 또는 Google의 서버로 가서 처리될 수 있습니다.
   - **iPhone·iPad**: 말로 할 일 만들기와 받아쓰기는 Apple 음성 인식 서버가 처리합니다. 말로 메모하기는 기기에서 인식할 수 있으면 기기에서, 아니면 Apple 서버에서 처리합니다.
   - **Android**: 기기에 해당 언어의 음성 인식 모델이 있으면 기기에서 처리하고, 그렇지 않으면 Google 음성 인식이 네트워크로 처리할 수 있습니다. 하위 할 일 받아쓰기는 네트워크로 처리될 수 있습니다.
   - 인식 정확도를 높이기 위해 자주 틀리는 일반 단어 목록을 함께 넘기며, 회원의 카테고리·할 일 이름은 기기에서 인식할 때만 넘깁니다.
2. **녹음 파일**: 녹음 파일을 저장하는 기능은 말로 메모하기뿐이며, 녹음 파일은 이용자 기기에 저장하고 회사 서버로 보내지 않습니다. 녹음과 받아 적은 글자·요약은 만든 날부터 30일 뒤 자동으로 삭제되고, 앱의 **마이** 탭 > **녹음 저장 공간**에서 먼저 지울 수 있습니다. 기기 백업에 포함될 수 있습니다.
3. **회사 서버로 가는 것**: 정리를 요청하면 받아 적은 글자만 회사 서버와 AI 업체로 보내며(제8조), 회사 서버는 이 글자를 저장하지 않습니다.
4. **다른 사람의 목소리**: 회의·수업 등 다른 사람의 말을 녹음할 때는 관련 법령을 지키고 필요한 경우 미리 동의를 받아 주세요.

## 제9조 (자동화된 결정에 관한 사항)

1. 서비스는 AI 및 자동화 기술을 활용하여 다음과 같은 **자동화된 결정**을 수행할 수 있습니다.
   - 문장·말·메모를 할 일로 자동 정리 (제목, 날짜, 카테고리 등 추출). 이용자가 확인한 뒤에 저장
   - 주간·월간 AI 리포트 자동 생성 (프리미엄 사용자 대상)
   - 반복 패턴 감지 및 반복 할 일 자동 제안 (프리미엄 사용자 대상)
   - 할 일 리마인더 자동 발송 (설정된 시간 기준 1시간 전·10분 전)
   - 요금제에 따른 기능 이용 제한 (월별·일별 이용 횟수 등)
2. 자동화된 결정은 회원의 권리 또는 의무에 **중대한 영향**을 미치지 않으며, 참고 정보 제공 또는 서비스 운영을 위한 것입니다.
3. 회원은 자동화된 결정에 대해 다음의 권리를 행사할 수 있습니다.
   - 자동화된 결정에 대한 **설명을 요구**할 수 있습니다.
   - 자동화된 결정에 대해 **이의를 제기**하고 인적 개입에 의한 재처리를 요구할 수 있습니다.
4. 위 권리 행사는 고객 문의 이메일(matthew@redband.co.kr)로 요청할 수 있습니다.

## 제10조 (자동 수집 장치(SDK)의 운영 및 거부)

1. 회사는 서비스 개선 및 오류 대응을 위해 다음의 SDK(Software Development Kit)를 사용하여 정보를 자동으로 수집합니다.

   | SDK | 운영 목적 | 수집 항목 |
   |-----|----------|----------|
   | **Firebase Analytics** | 서비스 이용 통계, 사용자 행동 분석 | 화면 조회, 이벤트 로그, 기기 정보, 세션 정보 |
   | **Sentry** | 앱·서버 오류 추적, 안정성 모니터링 | 오류 로그, 요청 정보, 기기 정보, 오류가 난 화면의 재현 기록(글자·이미지는 가려서 수집) |

2. **행태 정보 수집 안내**: Firebase Analytics를 통해 회원의 앱 내 행동 정보(화면 조회, 기능 사용 패턴 등)를 수집하여 서비스 개선에만 활용합니다. 광고 식별자는 수집하지 않으며, 말한 내용·받아 적은 글자·할 일 제목은 분석 이벤트에 넣지 않습니다.
3. **수집 거부 방법**: 이용자는 기기의 설정에서 분석 데이터 공유를 제한하거나, 앱을 삭제하여 자동 수집을 거부할 수 있습니다. 다만, 수집을 거부하는 경우 서비스 품질 개선이 제한될 수 있습니다.

## 제10조의2 (알림과 광고성 정보)

1. **서비스·거래 알림**: 할 일 리마인더, 날씨 알림, 친구 소식, AI 리포트, 사용법 안내, 서비스 공지와 무료 체험 종료 3일 전·연간 구독 갱신 7일 전·보상 프리미엄 종료 안내 같은 거래 알림은 기기 알림을 허용한 회원에게 보냅니다. 앱의 **마이** 탭 > **알림 설정**이나 기기 설정에서 끌 수 있으며, 결제 관련 안내는 끄더라도 스토어의 구독 정보에서 확인할 수 있습니다.
2. **광고성 알림**: 이벤트·혜택 소식과 복귀 안내, 스트릭 위기·점심 알림, 콕 찌르기 제안, 소셜 다이제스트, AI 반복 할 일 제안 알림, 친구 초대 조건 알림 같은 참여 유도 알림은 **광고성 앱 푸시 수신에 따로 동의한 회원에게만** 보냅니다.
   - 푸시 제목 앞에 "(광고)"를 붙이고, 본문에 수신 거부 방법을 적으며, 알림의 **광고성 푸시 그만 받기** 버튼이나 앱의 **알림 설정**에서 언제든지 받지 않을 수 있습니다.
   - 오후 9시부터 다음 날 오전 8시 사이에는 광고성 알림을 보내지 않습니다.
   - 동의하거나 철회하면 처리한 날짜를 알려 드리고, 동의한 회원에게는 2년마다 동의 사실을 다시 알려 드립니다.
3. 광고성 정보 수신에 동의하지 않아도 서비스의 기본 기능과 서비스·거래 알림은 그대로 이용할 수 있습니다.

## 제12조 (이용자의 권리와 행사 방법)

1. 이용자(또는 법정대리인)는 언제든지 다음의 권리를 행사할 수 있습니다.
   - 개인정보 **열람** 요구
   - 오류 등이 있을 경우 **정정** 요구
   - **삭제** 요구
   - 처리 **정지** 요구
   - 동의 **철회**
   - 회원 **탈퇴** 요구
   - **개인정보 전송 요구** (개인정보보호법 제35조의2에 따른 전송요구권)
2. **전송요구권 안내**: 이용자는 자신의 개인정보를 본인 또는 제3자에게 전송할 것을 요구할 수 있습니다. 회사는 개인정보보호법 및 관련 시행령에 따라 전송 가능한 개인정보의 범위, 전송 형식 등을 안내하고, 요구에 따라 처리합니다.
3. 권리 행사는 서면, 이메일(matthew@redband.co.kr), 또는 서비스 내 설정을 통해 가능하며, 회사는 이에 대해 지체 없이 조치합니다.
   - **회원 탈퇴(계정 삭제)**: 앱의 **마이** 탭 가장 아래 **탈퇴하기**에서 바로 할 수 있으며, 앱을 쓸 수 없다면 [계정 삭제 요청 안내](/ko/account-deletion)에 따라 이메일로 요청할 수 있습니다.
   - **AI 기능 데이터 제공 동의 철회**: 앱의 **마이** 탭 > **약관 및 정책** > **AI 기능 데이터 제공**에서 언제든지 철회할 수 있습니다. 철회한 뒤에는 AI 기능에 데이터를 보내지 않으며, 이미 만든 할 일은 그대로 남습니다.
   - **광고성 정보 수신 동의 철회**: 앱의 **마이** 탭 > **알림 설정**에서 마케팅 수신 동의와 광고성 앱 푸시를 끌 수 있습니다.
   - **녹음 삭제**: 앱의 **마이** 탭 > **녹음 저장 공간**에서 녹음을 하나씩 또는 모두 지울 수 있습니다.
   - **차단 해제**: 앱 설정의 **차단한 사용자**에서 언제든지 차단을 해제할 수 있습니다.
4. 이용자가 개인정보의 오류에 대한 정정을 요구한 경우, 정정을 완료하기 전까지 해당 정보를 이용하거나 제공하지 않습니다.
5. 이용자의 권리 행사는 법정대리인이나 위임을 받은 자 등 대리인을 통하여 할 수 있으며, 이 경우 개인정보보호법 시행규칙에 따른 위임장을 제출하여야 합니다.

## 제13조 (개인정보 보호를 위한 조치)

회사는 개인정보의 안전한 처리를 위해 다음과 같은 기술적·관리적·물리적 보호 조치를 시행합니다.

### 기술적 조치
- 개인정보의 암호화: 비밀번호는 Argon2id 알고리즘으로 해시 처리, 민감 정보(토큰 등)는 AES-256-GCM으로 암호화 저장
- 데이터 전송 구간 암호화 (HTTPS/TLS)
- 접근 권한 최소화 및 접근 통제
- 보안 업데이트 및 취약점 점검

### 관리적 조치
- 개인정보 취급자 최소화
- 개인정보 접근 기록 관리 및 모니터링
- 내부 보안 정책 수립 및 시행

### 물리적 조치
- 클라우드 서비스(Amazon Web Services 서울 리전) 기반 인프라 운영으로 물리적 보안은 클라우드 제공자 정책에 따름

## 공식 웹사이트 이용 분석 안내 (2026년 10월 4일 추가, 2026년 10월 27일 변경)

이 안내는 aido.kr 공식 웹사이트의 방문 분석에 적용됩니다. 처음 방문하면 화면 아래의 작은 카드에서 Google&nbsp;Analytics 쿠키 사용을 **허용**하거나 **거부**할 수 있고, 웹사이트 하단의 **쿠키 설정**에서 언제든 다시 바꿀 수 있어요. 거부해도 모든 콘텐츠와 스토어 링크를 이용할 수 있어요. 선택은 브라우저에 180일 동안 저장해요. 브라우저의 Do Not Track 또는 Global Privacy Control 신호가 켜져 있으면 저장된 선택과 관계없이 거부한 것으로 처리하고 카드를 띄우지 않으며, Google&nbsp;Analytics 스크립트도 불러오지 않아요.

- **Google&nbsp;Analytics 4 (Google LLC)**: 페이지 방문, 유입 출처, 캠페인, 언어, 기능 사용법 카드 선택, 스토어 버튼 클릭, 초대 코드 복사 여부를 분석해 웹사이트를 개선합니다. Google 동의 모드(Consent Mode v2)를 사용해요. 허용하기 전이나 거부한 경우에는 분석 쿠키를 저장하거나 읽지 않고, 쿠키 없이 방문·기기·브라우저 관련 정보만 Google로 전송돼 집계·모델링에 쓰일 수 있어요. **허용**하면 분석 쿠키(`_ga`)로 재방문을 구분합니다. 광고 저장·광고 사용자 데이터·광고 개인화 동의는 항상 거부 상태이며 Google Signals를 사용하지 않습니다. 스토어 버튼 클릭은 실제 앱 설치나 구매를 의미하지 않아요.
- **Vercel Web Analytics (Vercel Inc.)**: 쿠키를 쓰지 않고 개인을 식별하지 않는 집계 방문 통계로, 동의 선택과 관계없이 동작해요. 페이지, 유입 출처, 기기·브라우저 종류, 위 이벤트를 집계합니다.
- 분석에 회원 식별자, 이메일, 할 일·메모 내용, 초대 코드, 임의의 URL 쿼리와 해시를 보내지 않아요. 초대 링크 주소는 코드를 지운 경로로만 집계하고, 캠페인용 UTM 값은 정해진 형식의 값만 사용합니다.
- **거부**로 바꾸면 Google&nbsp;Analytics 쿠키 사용을 멈추고 해당 사이트의 Google&nbsp;Analytics 쿠키를 지웁니다. 이미 수집된 데이터는 각 분석 서비스의 보관 설정에 따라 처리되며, 선택 변경이 과거 데이터 삭제를 뜻하지는 않아요.

분석 서비스의 처리에 관한 내용은 [Google의 개인정보처리방침](https://policies.google.com/privacy)과 [Vercel Web Analytics 개인정보 안내](https://vercel.com/docs/analytics/privacy-policy)에서 확인할 수 있어요. 웹사이트 분석 관련 문의는 matthew@redband.co.kr로 보내 주세요.

## 친구 초대 보상 부정 사용 방지 안내 (2026년 10월 26일 추가)

친구 초대 보상을 같은 기기나 같은 계정 정보로 반복해서 받는 것을 막기 위해, 초대를 수락할 때 앱 설치 식별자(iOS IDFV·Android ID)와 인증한 이메일 또는 소셜 로그인 계정 ID를 되돌릴 수 없는 방식(HMAC-SHA256)으로 변환한 값만 저장해요. 이 값은 계정과 연결되지 않으며, 부정 사용 방지를 위해 회원 탈퇴 뒤에도 보관해요.

중복 보상을 막기 위해 앱 설치 식별자를 기기 키체인에 저장하며, 앱을 삭제해도 기기를 초기화하기 전까지 남을 수 있어요. 서버에는 이 값을 되돌릴 수 없게 변환(해시)한 값만 저장해요.

## 차단·신고 안내 (2026년 10월 26일 추가)

원하지 않는 상대와의 연결을 끊고 부적절한 콘텐츠를 알릴 수 있도록 차단과 신고 기능을 제공해요.

- **차단**: 회원을 차단하면 차단한 회원과 차단된 회원, 차단 시점을 저장해요. 두 사람의 친구 관계와 대기 중인 친구 요청은 바로 해제되고, 서로의 할 일·댓글·콕 찌르기·응원 기록이 보이지 않아요. 차단된 회원은 차단한 회원에게 친구 요청, 초대 코드로 친구 맺기, 콕 찌르기·응원, 댓글·답글·좋아요를 할 수 없어요. 차단 사실은 상대에게 알리지 않아요.
- **차단 해제**: 앱 설정의 **차단한 사용자**에서 해제하면 차단 기록을 지워요. 끊긴 친구 관계는 되살리지 않으므로 다시 친구가 되려면 친구 요청을 보내야 해요.
- **신고**: 프로필, 할 일, 댓글, 콕 찌르기 메시지, 응원 메시지를 신고할 수 있어요. 신고하면 신고한 회원, 신고된 회원, 신고 대상의 종류와 ID, 사유(스팸·광고, 괴롭힘·욕설, 부적절한 내용, 사칭, 기타), 직접 적은 상세 내용(선택, 500자 이내), 처리 상태와 신고 시점을 저장해요. 신고된 콘텐츠의 원문은 신고 기록에 따로 복사하지 않아요.
- **운영자 확인**: 신고가 접수되면 운영자가 검토할 수 있도록 신고 ID, 두 회원의 사용자 태그와 ID, 대상 종류·ID, 사유, 상세 내용을 이메일 발송 서비스(Resend)를 통해 고객센터 메일함으로 보내요. 신고한 회원의 이메일 주소는 담지 않으며, 신고 내용과 신고한 사람은 신고된 회원에게 알리지 않아요.
- **보관과 삭제**: 차단 기록은 차단을 해제하거나 어느 한쪽 계정이 영구 삭제될 때까지, 신고 기록은 신고한 회원 또는 신고된 회원의 계정이 영구 삭제될 때까지 보관해요. 운영자 메일함의 신고 접수 알림은 신고 처리와 관련 분쟁 대응에 필요한 기간 동안 보관한 뒤 파기해요.

이 안내는 2026년 10월 26일에 미리 게시하며, 아이두 앱에서 차단·신고 기능을 제공하는 날(앱 1.13.0 출시일)부터 적용해요.
